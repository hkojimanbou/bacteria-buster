## 1. アプリのコアコンセプト
日常のストレスやざわつく感情を整理するための「認知行動療法（CBT）」をベースにしたセルフケアアプリ。
単なるメモ帳ではなく、ユーザーが日々の生活の中で発生する「自動思考」に気づき、考え方のクセを修正していく**「心の筋トレを行うジム」**という位置づけです。スマートフォンでの利用がメインのターゲットです。

## 2. 必須の機能要件（実装済みの機能）
以下の機能・データ要件は満たすように構築してください。

1. **トップ画面**
   - 新規トレーニング開始への導線。
   - 過去の記録一覧への導線。
   - 各トレーニングの累計実施回数の表示。
2. **自動思考キャッチトレーニング Lv.1**
   - STEP1(事実) 〜 STEP5(行動)の入力。
   - NRSスケール（0〜10の数値評価）のスライダー。
3. **認知再構成法 Lv.1**
   - STEP1(自動思考) 〜 STEP9(推論の誤り)までの深掘り入力。
4. **共通の機能要件**
   - **ガイド機能**: 各ステップで「何を書けばいいのか」をユーザーが確認できるヘルプ。
   - **テキストコピー機能**: 記入した内容をSNSやコミュニティ用にフォーマットしてクリップボードにコピー。
   - **オートセーブ**: 入力途中で離脱しても、次回新規作成時に途中から再開できる機能。
   - **AIタイトル自動生成**: 確定保存時、タイトルが空欄なら入力内容を元に自動でタイトルを付与する（現在はモック実装でOK）。
5. **過去の記録と編集**
   - 過去の記録を種類ごとに一覧表示し、タップで復元・再編集・上書き保存が可能。

## 3. 技術スタック
- **フロントエンド**: React 18, TypeScript, Vite
- **スタイリング**: Tailwind CSS
- **アイコン**: Lucide React
- **ルーティング**: React Router (v6)
- **データ保存**: ブラウザの Local Storage（一時保存用キーと確定済みデータ用キーを分離）
