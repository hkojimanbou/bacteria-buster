# CBTジムアプリ 開発引継ぎ書

本ドキュメントは、これまでに開発を進めてきた「CBTジムアプリ（認知行動療法セルフケアアプリ）」のプロジェクト全般にわたる仕様、開発の背景（最初の指示・コンセプト）、技術構成、および今後の開発に向けた引き継ぎ情報をまとめたものです。

---

## 1. プロジェクトの原点とコンセプト

### 1.1. 開発の背景と目的
本プロジェクトは、**日常のストレスやざわつく感情を整理するための「認知行動療法（CBT）」をベースにしたセルフケアアプリ**を作るという構想からスタートしました。
単なるメモ帳ではなく、ユーザーが日々の生活の中で発生する「自動思考」に気づき、考え方のクセを修正していく**「心の筋トレを行うジム」**のような位置づけのアプリを目指しています。

### 1.2. ターゲットと目指すUX（ユーザー体験）
- **手軽な記録**: 感情が動いた直後、またはその日の夜に、スマートフォンからサッと記録できる直感的でレスポンシブなモダンUI。
- **振り返りと再構成**: 記録した内容を後から見返し、自分の思考の癖（推論の誤り）に気づいて柔軟な考え方に書き換える（認知再構成法）プロセスをサポート。
- **コミュニティへの共有**: 記録した内容を手軽にテキスト化し、外部のコミュニティやSNSに共有してフィードバックをもらえる仕組み（テキスト出力機能）。

---

## 2. 現在実装されている主要機能

現在、フロントエンド（React）を中心としたプロトタイプ〜MVP（Minimum Viable Product）として以下の機能が実装・稼働しています。

### 2.1. トップ画面 (`Home.tsx`)
- 新しいトレーニング（自動思考キャッチ、認知再構成法）を始めるためのわかりやすい導線。
- 各トレーニングの累計実施回数の表示。
- 過去の記録一覧画面へのリンクボタン。

### 2.2. 自動思考キャッチトレーニング Lv.1 (`AutoThoughtCatch.tsx`)
- STEP1（事実）〜 STEP5（行動）およびNRSスケール（数値評価）の入力画面。
- 各項目の書き方や目的を解説する「ガイド機能」。
- **オートセーブ機能**: 入力途中で画面を閉じても、次回開いた際に途中から再開可能。
- **クリップボード出力機能**: コミュニティへの投稿用に、入力内容を自動でフォーマットしてコピーする機能。

### 2.3. 認知再構成法 Lv.1 (`CognitiveRestructuring.tsx`)
- STEP1（自動思考）〜 STEP9（推論の誤り）までの深掘り入力画面。
- 「部分否定文の作成」や「反証出し」など、CBTの核となるプロセスをステップバイステップでナビゲート。

### 2.4. 過去の記録一覧・編集機能 (`HistoryList.tsx`)
- 保存したトレーニングの履歴を種類ごとに一覧表示。
- 対象を選択すると過去の入力内容が復元され、再編集および上書き保存が可能。

### 2.5. AIタイトル自動要約機能 (`utils/ai.ts`)
- タイトルを空欄にして「確定（保存）」した際、入力内容をもとに自動でタイトルを生成し付与する仕組み。
- *(※現状は1秒後にダミーのタイトルを返すモック（仮実装）となっており、今後のAPI連携に向けた土台として構築しています)*

## 3. 技術スタックとデータ構造

### 3.1. 技術構成
- **フレームワーク**: React 18 (Viteによる高速なビルド環境)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS (Utility-First CSS) / Vanilla CSS によるグラスモーフィズムなどのリッチな装飾
- **アイコン**: Lucide React
- **ルーティング**: React Router (v6)
- **ホスティング/デプロイ**: Vercel

### 3.2. データ保存（現状の仕様）
- **ブラウザの Local Storage** を使用してデータを保存しています。（バックエンドDBは未導入）
- 一時保存（ドラフト）データと、確定保存済みデータでキーを分離し、データが混線しないように管理しています。

### 3.3. 主要なディレクトリ構成
```text
cbt-app/
├── src/
│   ├── components/       # 再利用可能なUIパーツ (スライダー、ガイドなど)
│   ├── hooks/            # カスタムフック (useAutoSave.ts 等)
│   ├── pages/            # 各画面のコンポーネント
│   ├── utils/            # ユーティリティ (ai.ts, storage.ts 等)
│   ├── App.tsx           # ルーティング設定
│   ├── index.css         # グローバルスタイル・Tailwind設定
│   └── types.ts          # TypeScriptの型定義
```

## 4. 今後の開発課題とネクストステップ（拡張アイデア）

現状のアプリをさらに進化させ、本格的な「CBTジムアプリ」として完成させるための推奨課題です。

1. **AI連携の実装（Gemini API / OpenAI API の導入）**
   - 現在モックとなっているタイトル生成機能を本物のAIに置き換えます。
   - さらに、ユーザーが認知再構成法の「リライト（部分否定文）」や「反証」で行き詰まった際に、AIがヒントを出したり、推論の誤りを指摘してくれる**「AIコーチ機能」**への発展が期待できます。
2. **バックエンド・データベースと認証の導入 (Firebase / Supabase)**
   - 現在のデータは端末ごとに独立しています。ログイン機能（アカウント作成）を実装し、クラウド上にデータを保存することで、機種変更時のデータ引き継ぎや、複数端末での共有が可能になります。
3. **継続を促すゲーミフィケーション要素**
   - トレーニングの実施回数に応じたレベルアップ、バッジの付与、カレンダーでの継続日数の可視化など、「ジムに通う」感覚を強化する機能の追加。
4. **PWA（Progressive Web App）化**
   - スマホのホーム画面に「アプリ」としてインストールできるようにし、よりネイティブアプリに近い体験を提供します。
