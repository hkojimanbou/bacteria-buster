# 🦠 細菌撲滅 (Bacteria Buster)

Phaser 3 + TypeScript で開発された、スマートフォン対応の「細菌撲滅」パズルゲーム再現プロジェクトです。

---

## 🎮 プレイ方法

- **カプセルの移動**: 左右にドラッグしてカプセルを動かします。
- **カプセルの回転**: タップするとカプセルが90度回転します。
- **消去ルール**: 同じ色（赤・黄・青）のブロックまたは細菌を縦横どちらかに **4つ以上** 並べると消去されます。
- **重力・連鎖**: ブロックが消去された後、空中に浮いたカプセルの切れ端や細菌は自動的に落下し、連続で4つ以上揃うと「連鎖（CHAIN）」が発生してハイスコアを獲得できます！

---

## 📈 ゲーム仕様

- **レベル機能**: クリアするたびにレベルが上がり、配置される細菌の数が増大し、落下スピードが加速します。
- **スコア機能**: 消去したセル数と連鎖数に応じてスコアが加算されます。
- **サウンド機能**: Web Audio API を使用し、レトロゲーム風の効果音がすべてプログラム生成で再生されます。
